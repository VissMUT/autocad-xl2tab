# XL2TAB - Excel - связанные таблицы AutoCAD (DataLink)

Плагин .NET для полного AutoCAD 2019+ (Windows). Создаёт в чертеже по одной
**связанной таблице** на каждый выбранный лист Excel-файла. Связи ссылаются
**напрямую на исходный файл** - `DATALINKUPDATE` подтягивает изменения из Excel.

> Важные факты (подтверждено диагностикой на AutoCAD 2019):
> - В COM/ActiveX-интерфейсе AutoCAD **нет доступа к DataLinks**
>   (`vla-get-datalinks` не существует), поэтому плагин на .NET (NETLOAD),
>   а не AutoLISP. Старые LISP-наброски - `legacy-lsp\`.
> - **Рабочий формат связи:** connection string `путь!Лист!A1:N40`,
>   адаптер **`ACEXCEL`** (читает xlsx через ACE-провайдер, без Excel),
>   имя листа **без кавычек** (кириллица и пробелы - OK).
>   Современный формат `ACEXCEL;DataSource=...` через API не работает
>   (`eDataLinkSourceNotFound`); адаптер `AcExcel` работает, но медленно.
> - Адаптировано из открытых примеров: `sonicg83/AutoCad.net`,
>   `55kwukai/PSH-DesignSystem`; справочник по структуре DATALINK - LibreDWG
>   `examples/alldxf_DATALINK.inc`.

## Требования

- Полный AutoCAD 2019+ (Windows). AutoCAD LT не подходит.
- Для `.xlsx` **Excel не нужен** - имена листов, диапазоны и размеры читаются
  напрямую из файла (ZIP/XML), данные тянутся нативным адаптером AutoCAD.
- Для `.xls` (и нестандартных xlsx) - фолбэк через установленный Excel COM.

## Установка

1. Закройте AutoCAD (старая DLL остаётся загруженной в памяти сессии -    нельзя просто перезаписать файл).
2. Откройте AutoCAD - `NETLOAD` - выбрать **`xl2tab_v10.dll`**.
3. Доступны команды `XL2TAB` и `XLTABDIAG2`.
4. Для автозагрузки: `APPLOAD` - «Содержимое» - добавить DLL в Startup Suite.

## Скорость

- `.xlsx` читается напрямую из ZIP - Excel-процесс не запускается.
- Связи на адаптере `ACEXCEL` (ACE-провайдер) - обновление ~1.3 с на связь
  после первого (разового) прогрева; без Excel-COM.
- Обновление связей - по одной (`DataLink.Update`), а не глобально по всем:
  на длинных листах с разбивкой нет квадратичного замедления.

## Использование

1. `XL2TAB` - выбрать `.xlsx`/`.xls`.
2. Номера листов через запятую (`Enter` = все видимые).
3. Диапазон (`Enter` = весь лист, можно `A5:N40` - один на все выбранные листы).
4. Масштаб размеров (`Enter` = 1.0).
5. **«Разбивать по высоте? [Да/Нет] <Нет>»** - нарезка длинного листа на
   отдельные таблицы (каждую можно разместить на своём листе компоновки).
6. Если «Да» - две высоты (первый лист имеет большой штамп, последующие -    меньший):
   - **«Макс. высота таблицы для 1-го листа, мм <232>»**
   - **«Макс. высота таблицы для последующих листов, мм <247>»**
   (232 = А3 альбомная 287 мм внутри рамки − штамп 55; 247 = − штамп 40).
7. Точка вставки первой таблицы (`Enter` = 0,0).

### Разбивка по высоте (под А3)

- **Шапка** = первая строка выбранного диапазона. Она подключается **отдельной
  datalink-связью** (`XL2TAB_<лист>_ШАПКА`), поэтому её **форматирование
  (шрифт, жирность, выравнивание) приходит из Excel** и сохраняется при
  `DATALINKUPDATE`, а не копируется голым текстом.
- **Данные** = строки диапазона со 2-й; режутся на куски: первый кусок каждого
  листа Excel считается «листом 1» (лимит 1), остальные - «листами 2+» (лимит 2).
  Высота куска = шапка + строки данных ≤ лимит; строка выше лимита идёт одна.
- **Каждый кусок** = отдельная связь `XL2TAB_<лист>_Ч<n>` + **отдельная таблица**
  (в таблице две связи: шапка на строке 0, данные со строки 1).
- Таблицы ставятся столбиком с зазором 15 мм; каждую потом можно свободно
  двигать на свой лист.
- Если суммарная ширина > 390 мм - предупреждение (не влезет в А3 альбомную).

## Диагностика (если что-то не работает)

`XLTABDIAG2` в пустом чертеже: создаёт тестовый xlsx (листы: латиница,
кириллица, с пробелом), прогоняет тесты SZ (чтение xlsx напрямую),
TB/TC/TD1/TF + TE (две связи в таблице с двойным обновлением) и пишет
`%TEMP%\xltabdiag_log.txt`. Лог покажет, на каком шаге проблема.

## Обновление данных

- `DATALINKUPDATE` - «All» - перечитать все связи из исходного xlsx.
- Палитра «Внешние ссылки» (`XREF`) - Data Links - редактирование, отсоединение.
- `DataLinkOption.PersistCache` включён - данные кэшируются в чертёж,
  таблицы видны даже при недоступном файле.
- Повторное обновление может вернуть высоты строк/ширины колонок «как в
  Excel» (без вашего масштаба) - в этом случае просто запустите `XL2TAB` заново
  (связи пересоздаются, размеры переприменяются).

## Размеры и оформление

- Ширина колонки: символы Excel - мм = `(W*7+5) * 25.4/96 * масштаб`.
- Высота строки: пункты - мм = `пункты * 25.4/72 * масштаб`.
- Минимум 5 мм на колонку/строку (скрытые строки/колонки).
- Перед запуском настройте текущий табличный стиль (например, шрифт
  «ГОСТ 2.304-81» / `isocpeur`, высота текста 2.5 мм).

## Ограничения

- **Объединённые ячейки:** DataLink отдаёт текст только левой верхней ячейки.
- **Формулы:** читаются кэшированные значения - сохраните файл из Excel
  перед конвертацией (файлы без кэша дадут пустые ячейки).
- Скрытые листы пропускаются.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Или вручную (csc.exe из .NET Framework + AutoCAD 2019):

```powershell
& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' /nologo /target:library `
  /out:"xl2tab_v10.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\AcCoreMgd.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\acdbmgd.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\acmgd.dll" `
  /r:System.Windows.Forms.dll /r:System.dll `
  /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll /r:System.Xml.dll `
  "xl2tab.cs"
```

Если DLL уже загружена в AutoCAD, скомпилировать в тот же файл не удастся
(файл заблокирован) - закройте AutoCAD или собирайте в файл с новым именем.
