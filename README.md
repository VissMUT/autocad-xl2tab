# XL2TAB - Excel в связанные таблицы AutoCAD (DataLink)

Плагин .NET для полного AutoCAD 2019+ (Windows). Создаёт в чертеже по одной
**связанной таблице** на каждый выбранный лист Excel-файла. Связи ссылаются
**напрямую на исходный файл**: `DATALINKUPDATE` подтягивает изменения из Excel.

> Важные факты (подтверждено диагностикой на AutoCAD 2019):
> - В COM/ActiveX-интерфейсе AutoCAD **нет доступа к DataLinks**
>   (`vla-get-datalinks` не существует), поэтому плагин на .NET (NETLOAD),
>   а не AutoLISP. Старые LISP-наброски - `legacy-lsp\`.
> - **Рабочий формат связи:** connection string `путь!Лист!A1:N40`,
>   адаптер **`ACEXCEL`** (читает xlsx через ACE-провайдер, без Excel),
>   имя листа **без кавычек** (кириллица и пробелы - OK).
>   Современный формат `ACEXCEL;DataSource=...` через API не работает
>   (`eDataLinkSourceNotFound`); адаптер `AcExcel` работает, но медленно.
> - Адаптировано из открытых примеров: `sonicg83/AutoCad.net`,
>   `55kwukai/PSH-DesignSystem`; справочник по структуре DATALINK - LibreDWG
>   `examples/alldxf_DATALINK.inc`.

## Требования

- Полный AutoCAD 2019+ (Windows). AutoCAD LT не подходит.
- Для `.xlsx` **Excel не нужен**: имена листов, диапазоны и размеры читаются
  напрямую из файла (ZIP/XML), данные тянутся нативным адаптером AutoCAD.
- Для `.xls` (и нестандартных xlsx) - фолбэк через установленный Excel COM.

## Установка

### Вариант 1: автозагрузка (рекомендуется)

Один раз запустите из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт копирует бандл в `%APPDATA%\Autodesk\ApplicationPlugins\XL2TAB.bundle\`
(права администратора не нужны). После перезапуска AutoCAD команды доступны
**всегда, без NETLOAD**.

### Вариант 2: ручная загрузка

`NETLOAD` - выбрать `xl2tab_v15.dll` (загружено до перезапуска AutoCAD).
Или `APPLOAD` - «Содержимое» - добавить DLL в Startup Suite.

### Обновление версии

Замените DLL в установленном бандле (при закрытом AutoCAD) и запустите
`install.ps1` снова, либо просто повторно выполните `install.ps1`
с новой версией DLL в папке репозитория.

## Кнопка на ленте и панель инструментов

После загрузки плагина на ленте AutoCAD появляется вкладка **XL2TAB**:

- большая кнопка **«XL2TAB / Палитра»** - открыть палитру настроек;
- **«Пошагово»** - пошаговый режим (`XL2TABPROMPT`);
- **«Диагностика»** - `XLTABDIAG2`.

Если лента отключена (классический интерфейс): плагин создаёт **панель
инструментов XL2TAB** с теми же тремя кнопками (создаётся при загрузке
плагина и командой `XL2TAB`).

## Команды

- **`XL2TAB`** - палитра настроек (закрепляется как «Свойства»):
  файл, листы-чекбоксы, диапазон, масштаб, разбивка по высоте, кнопка
  «Создать таблицы». После нажатия палитра прячется, в чертеже запрашивается
  точка вставки.
- **`XL2TABPROMPT`** - пошаговый режим (все вопросы в командной строке).
- **`XLTABDIAG2`** - диагностика в пустом чертеже, лог
  `%TEMP%\xltabdiag_log.txt`.

## Использование палитры

1. `XL2TAB` - открыть палитру.
2. «Выбрать файл...» - `.xlsx`/`.xls`; листы появятся с галочками.
3. Отметить нужные листы (кнопки «Все»/«Ничего»).
4. Диапазон (пусто = весь лист, можно `A5:N40` - один на все листы).
5. Масштаб размеров (`1.00` = 1:1 от Excel).
6. «Разбивать по высоте (под А3)» - если нужно; высоты:
   - для 1-го листа (большой штамп) - 232 мм;
   - для последующих (штамп меньше) - 247 мм.
7. «Создать таблицы» - клик точки вставки в чертеже (Enter = 0,0).

## Разбивка по высоте (под А3)

- **Шапка** = первая строка выбранного диапазона. Подключается **отдельной
  datalink-связью** (`XL2TAB_<лист>_ШАПКА`), поэтому её форматирование
  (шрифт, жирность, выравнивание) приходит из Excel и сохраняется при
  `DATALINKUPDATE`.
- **Данные** = строки диапазона со 2-й; режутся на куски: первый кусок
  каждого листа Excel считается «листом 1» (лимит 1), остальные -
  «листами 2+» (лимит 2).
- **Каждый кусок** = отдельная связь `XL2TAB_<лист>_Ч<n>` + отдельная таблица
  (в таблице две связи: шапка на строке 0, данные со строки 1).
- Таблицы ставятся столбиком с зазором 15 мм; каждую можно свободно
  двигать на свой лист компоновки.
- Если суммарная ширина > 390 мм - предупреждение (не влезет в А3 альбомную).

## Скорость

- `.xlsx` читается напрямую из ZIP, Excel-процесс не запускается.
- Связи на адаптере `ACEXCEL` (ACE-провайдер).
- Обновление связей - по одной (`DataLink.Update`), а не глобально по всем.
- Тайминги каждого этапа пишутся в `%TEMP%\xltabdiag_log.txt`.

## Обновление данных

- `DATALINKUPDATE` - «All» - перечитать все связи из исходного xlsx.
- Палитра «Внешние ссылки» (`XREF`) - Data Links - редактирование,
  отсоединение.
- `DataLinkOption.PersistCache` включён: данные кэшируются в чертёж,
  таблицы видны даже при недоступном файле.
- Повторное обновление может вернуть высоты строк/ширины колонок «как в
  Excel» (без вашего масштаба). В этом случае запустите `XL2TAB` заново:
  связи пересоздаются, размеры переприменяются.

## Размеры и оформление

- Ширина колонки: символы Excel в мм = `(W*7+5) * 25.4/96 * масштаб`.
- Высота строки: пункты в мм = `пункты * 25.4/72 * масштаб`.
- Минимум 5 мм на колонку/строку (скрытые строки/колонки).
- Перед запуском настройте текущий табличный стиль (например, шрифт
  «ГОСТ 2.304-81» / `isocpeur`, высота текста 2.5 мм).

## Ограничения

- **Объединённые ячейки:** DataLink отдаёт текст только левой верхней ячейки.
- **Формулы:** читаются кэшированные значения. Сохраните файл из Excel перед
  конвертацией (файлы без кэша дадут пустые ячейки).
- Скрытые листы пропускаются.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Или вручную (csc.exe из .NET Framework + AutoCAD 2019):

```powershell
& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' /nologo /target:library `
  /out:"xl2tab_v15.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\AcCoreMgd.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\acdbmgd.dll" `
  /r:"C:\Program Files\Autodesk\AutoCAD 2019\acmgd.dll" `
  /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:System.dll `
  /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll /r:System.Xml.dll `
  /r:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\PresentationCore.dll" `
  /r:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\PresentationFramework.dll" `
  /r:"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF\WindowsBase.dll" `
  "xl2tab.cs"
```

Если DLL уже загружена в AutoCAD, скомпилировать в тот же файл не удастся
(файл заблокирован). Закройте AutoCAD или собирайте в файл с новым именем.
