# XL2TAB - Excel в связанные таблицы AutoCAD (DataLink)

Плагин .NET для полного AutoCAD 2019+ (Windows), который вставляет данные из
Excel-файла в чертёж **связанными таблицами** (DataLink). Таблицы остаются
связанными с исходным `.xlsx`: после правок в Excel данные обновляются командой
`DATALINKUPDATE` или через палитру «Внешние ссылки».

## Что умеет

- Перенос любого видимого листа Excel в таблицу AutoCAD за пару кликов.
- Выбор листов галочками (или по номерам в пошаговом режиме).
- Произвольный диапазон: весь лист (UsedRange) или, например, `A5:N40`.
- Копирование геометрии из Excel: ширина колонок и высота строк
  пересчитываются в миллиметры с масштабным коэффициентом.
- Автоматическое **разбиение длинного листа на несколько таблиц** так, чтобы
  каждая помещалась на лист А3 по высоте. Отдельные лимиты для первого и
  последующих листов (разные штампы), повтор шапки в каждой таблице.
- Форматирование шапки приходит из Excel (шрифт, жирность, выравнивание) и
  сохраняется при обновлении данных.
- Палитра настроек (закрепляется как «Свойства»), вкладка на ленте и
  классическая панель инструментов.
- Чтение `.xlsx` без запуска Excel (ZIP/XML), Excel нужен только для `.xls`.
- Диагностика `XLTABDIAG2` с подробным логом.

## Как это работает

Плагин создаёт в чертеже объекты DataLink (связи) и таблицы AutoCAD,
привязанные к этим связям. Связь указывает на файл Excel и конкретный
диапазон:

```
C:\Data\Спецификация.xlsx!Спецификация!A1:I34
```

Особенности реализации, найденные и подтверждённые на AutoCAD 2019:

- В COM/ActiveX-интерфейсе AutoCAD нет доступа к DataLinks
  (`vla-get-datalinks` не существует), поэтому плагин написан на .NET
  (NETLOAD), а не на AutoLISP.
- Рабочий формат связи: `путь!Лист!A1:N40`, адаптер `ACEXCEL`
  (ACE-провайдер, без Excel). Имя листа указывается без кавычек,
  кириллица и пробелы допустимы.
- Современный формат `ACEXCEL;DataSource=...` через API не работает
  (`eDataLinkSourceNotFound`).
- При разбивке в одной таблице используется две связи: шапка (строка 0) и
  данные (со строки 1). Шапка живёт отдельно от данных и не затирается при
  `DATALINKUPDATE`.
- Имена и размеры листов читаются напрямую из `.xlsx` (ZIP/XML), без Excel.
- Обновление связи выполняется точечно (`DataLink.Update`), а не глобально
  по всем связям, поэтому длинные листы не замедляют работу квадратично.

## Требования

- Полный AutoCAD 2019 или новее (Windows). AutoCAD LT не подходит: нет
  поддержки .NET-плагинов и DataLink.
- Microsoft Excel нужен только для `.xls` (старый формат) и нестандартных
  `.xlsx`. Для обычных `.xlsx` Excel не требуется.

## Установка

### Вариант 1: автозагрузка (рекомендуется)

Один раз запустите из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт копирует бандл (`xl2tab.dll` + `XL2TAB.cuix`) в
`%APPDATA%\Autodesk\ApplicationPlugins\XL2TAB.bundle\`. Права администратора
не нужны. После перезапуска AutoCAD команды доступны всегда, без NETLOAD.

### Вариант 2: ручная загрузка

`NETLOAD` и выбрать `xl2tab.dll` (действует до перезапуска AutoCAD). Можно
добавить DLL в Startup Suite через `APPLOAD` - «Содержимое».

### Обновление версии

Закройте AutoCAD, замените файлы в установленном бандле и запустите
`install.ps1` снова. При обновлении из репозитория: `build.ps1` собирает
`xl2tab.dll`, `tools\build-cuix.ps1` пересобирает панель `XL2TAB.cuix`,
`install.ps1` устанавливает оба файла.

## Интерфейс

### Лента и панель инструментов

После загрузки плагина доступны три точки входа:

- вкладка **XL2TAB** на ленте AutoCAD (если лента включена);
- классическая панель инструментов **XL2TAB** (для workspace без ленты);
- команды в командной строке.

Кнопки панели и ленты: «XL2TAB» (палитра), «Пошагово», «Диагностика». У всех
кнопок есть всплывающие подсказки с описанием и именем команды.

### Палитра XL2TAB

Команда `XL2TAB` открывает палитру (закрепляется как «Свойства»):

- **Выбрать файл...** - выбор `.xlsx`/`.xls`; рядом показывается имя файла.
- **Листы** - список видимых листов с галочками; кнопки «Все» и «Ничего».
- **Диапазон** - пусто = весь лист, либо `A5:N40`.
- **Масштаб размеров** - коэффициент для ширин и высот (1.00 = 1:1 от Excel).
- **Разбивать по высоте (под А3)** - включает нарезку длинного листа;
  рядом два поля: высота таблицы для 1-го листа (по умолчанию 232 мм) и для
  последующих (247 мм).
- **Создать таблицы** - палитра скрывается, в чертеже запрашивается точка
  вставки, затем создаются таблицы.

### Пошаговый режим XL2TABPROMPT

Все те же настройки, но вопросами в командной строке: файл, номера листов,
диапазон, масштаб, разбивка и высоты, точка вставки. Удобен для скриптов и
привычной работы без палитры.

## Использование

1. Откройте палитру: `XL2TAB` или кнопка «XL2TAB» на панели.
2. Выберите файл Excel.
3. Отметьте нужные листы галочками.
4. Укажите диапазон (Enter = весь лист).
5. Задайте масштаб (Enter = 1.00).
6. При необходимости включите «Разбивать по высоте» и задайте высоты.
7. Нажмите «Создать таблицы» и укажите точку вставки в чертеже
   (Enter = 0,0).

Таблицы вставляются столбиком сверху вниз с зазором 15 мм. Каждое имя связи
строится по шаблону `XL2TAB_<номер листа>_<имя листа>`, для разбитых таблиц
добавляется `_Ч<номер>` и `_ШАПКА`.

## Разбивка по высоте (под А3)

- **Шапка** - первая строка выбранного диапазона. Подключается отдельной
  связью, поэтому её форматирование приходит из Excel и переживает
  `DATALINKUPDATE`.
- **Данные** - строки диапазона со второй; нарезаются на куски так, чтобы
  высота куска (шапка плюс строки) не превышала заданный лимит. Строка,
  которая сама выше лимита, идёт отдельной таблицей.
- Первый кусок каждого листа Excel считается «листом 1» (лимит 1),
  остальные - «листами 2+» (лимит 2).
- Каждый кусок - отдельная таблица и отдельная связь, её можно свободно
  перенести на свой лист компоновки.
- Если суммарная ширина таблицы превышает 390 мм (А3 альбомная с рамкой
  ГОСТ), выводится предупреждение.

Типичные лимиты: 232 мм для первого листа (штамп 55 мм) и 247 мм для
последующих (штамп 40 мм) при внутренней высоте рамки 287 мм. Значения
задаются каждый раз в палитре, по умолчанию указаны именно эти.

## Обновление данных из Excel

- `DATALINKUPDATE` и вариант «All» - перечитать все связи из исходного xlsx.
- Палитра «Внешние ссылки» (`XREF`), раздел Data Links - просмотр,
  редактирование, отсоединение связей.
- Включён режим `PersistCache`: данные кэшируются в чертеже, таблицы видны
  даже если файл Excel недоступен.
- Повторное обновление может вернуть высоты строк и ширины колонок «как в
  Excel» (без вашего масштаба). В этом случае запустите `XL2TAB` заново:
  связи пересоздаются, размеры применяются снова.
- После правок в Excel файл нужно сохранить: AutoCAD читает кэшированные
  значения формул.

## Размеры и оформление

- Ширина колонки: символы Excel в миллиметры, `(W*7+5) * 25.4/96 * масштаб`.
- Высота строки: пункты в миллиметры, `пункты * 25.4/72 * масштаб`.
- Минимальный размер колонки и строки - 5 мм (на случай скрытых строк и
  колонок).
- Перед запуском настройте текущий табличный стиль AutoCAD: например, шрифт
  «ГОСТ 2.304-81» или `isocpeur`, высота текста 2.5 мм. Новые таблицы
  используют текущий стиль.

## Скорость

- `.xlsx` читается напрямую из ZIP, Excel-процесс не запускается.
- Связи работают через адаптер `ACEXCEL` (ACE-провайдер).
- Обновление выполняется по одной связи, без глобальных переобновлений.
- Первое обновление в сессии AutoCAD может быть медленнее (разовый прогрев
  фреймворка DataLink), далее связи обновляются быстро.
- Тайминги каждого этапа пишутся в лог `%TEMP%\xltabdiag_log.txt`.

## Диагностика

Команда `XLTABDIAG2` в пустом чертеже создаёт тестовый xlsx и проверяет
основные механизмы. Лог: `%TEMP%\xltabdiag_log.txt`.

Тесты в логе:

- `SZ` - чтение xlsx напрямую (имена листов, диапазоны, размеры).
- `TB`, `TC`, `TD1` - создание связи, латиница, кириллица, пробелы в имени
  листа.
- `TF` - адаптер `ACEXCEL` со старым синтаксисом строки подключения.
- `TE` - две связи в одной таблице (шапка и данные) с повторным обновлением.

Если что-то не работает, пришлите лог: в нём есть имена шагов и текст ошибок.

## Ограничения

- **Объединённые ячейки**: DataLink отдаёт текст только левой верхней
  ячейки объединения.
- **Формулы**: читаются кэшированные значения. Файлы, записанные сторонними
  библиотеками без кэша, дадут пустые ячейки - откройте и сохраните файл в
  Excel.
- Скрытые листы не переносятся.
- Диапазон задаётся один на все выбранные листы.
- Имя листа в строке подключения указывается без кавычек.
- AutoCAD LT не поддерживается.

## Устранение неполадок

- **Команды не появились после запуска AutoCAD.** Проверьте, что бандл лежит
  в `%APPDATA%\Autodesk\ApplicationPlugins\XL2TAB.bundle\` и содержит
  `PackageContents.xml` и `Contents\xl2tab.dll`. В `PackageContents.xml`
  должен быть `LoadOnAutoCADStartup="True"`.
- **Панель инструментов не видна.** Выполните `XL2TAB`: команда пересоздаёт
  панель и открывает палитру. В классическом интерфейсе панель можно включить
  правым кликом по панелям инструментов, пункт XL2TAB.
- **Таблица пустая.** Проверьте, что лист и диапазон существуют, а файл
  сохранён в Excel. Запустите `XLTABDIAG2` и посмотрите лог.
- **Данные не обновились.** Убедитесь, что Excel-файл сохранён, и выполните
  `DATALINKUPDATE` (All). Если таблица потеряла размеры, запустите `XL2TAB`
  заново.

## Сборка из исходников

Требуется `csc.exe` из .NET Framework и установленный AutoCAD 2019 (из него
берутся `AcCoreMgd.dll`, `acdbmgd.dll`, `acmgd.dll`, `AdWindows.dll`).

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\tools\build-cuix.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`build.ps1` собирает `xl2tab.dll`, `tools\build-cuix.ps1` создаёт панель
`XL2TAB.cuix` (иконки 16x16, 32bpp с прозрачностью), `install.ps1`
устанавливает бандл в ApplicationPlugins.

Если DLL уже загружена в AutoCAD, пересобрать её в тот же файл не получится
(файл заблокирован). Закройте AutoCAD перед сборкой.

